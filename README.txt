# SVD Mining Works — Website

This website was rebuilt from the supplied SVD Mining Works corporate profile PPTX.

## Included
- `index.html` — complete responsive website
- `assets/` — 14 unique visual assets extracted from the PPTX

## Source-derived sections
Company overview, four core capabilities, leadership, mission/standards, fleet schedule,
project portfolio, project values, execution scale, contact details and operating principles.

## Important source note
The PPTX contains both an "established in 2019" narrative and a company profile field stating
"ESTABLISHED 2014". The website uses 2014 as the headline timeline because the profile cover and
company-at-a-glance sections also use 2014–present, while avoiding a new unsupported claim about
which date is legally definitive.

Open `index.html` in a browser or upload the whole `svd-mining-website` folder to your hosting provider.
